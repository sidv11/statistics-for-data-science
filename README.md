# Day 6 — Statistics for Data Science

This project explains hypothesis testing and A/B testing using a synthetic e-commerce experiment.

## Questions answered

1. Does a redesigned checkout page change average session time?
2. Does it change conversion rate?

## Topics

- Descriptive statistics
- Null and alternative hypotheses
- p-values
- Independent two-sample Welch t-test
- Chi-square test of independence
- Conversion uplift
- Confidence intervals
- Statistical vs business significance

## Run

```bash
pip install -r requirements.txt
jupyter notebook day6_statistics_for_ds.ipynb
```

The dataset is synthetic and created inside the notebook for learning.
